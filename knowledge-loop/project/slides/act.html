(약 50초) 다음은 행동입니다. 루프에서 배우려면 먼저 행동하고 그 결과를 봐야 합니다. 기본 형태는 ReAct 루프로, 무엇을 할지 생각하고, 도구를 부르고, 결과를 보고, 다시 생각하기를 반복합니다. 도구 호출은 함수 이름과 인자 형식을 알려 주면 LLM이 골라 부르는 방식이고, MCP는 이런 도구와 데이터 연결을 표준화해서 한 번 만든 연결을 여러 에이전트가 쓸 수 있게 합니다. 격리된 환경에서 코드를 직접 돌려 분석이나 계산을 하기도 합니다. 정해진 순서로 도는 워크플로는 예측 가능하고, 스스로 계획하는 에이전트는 유연해서 보통 섞어 씁니다. 실행과 검토를 다른 에이전트가 맡으면 실수를 더 잘 잡습니다. 그리고 권한은 나눠야 합니다. 특히 망 설정 변경 같은 쓰기 권한은 가장 좁게 줍니다.
