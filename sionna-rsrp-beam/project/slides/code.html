입력 ④ · R1 코드 뼈대

빔마다 패턴을 바꿔 지도를 그린다

# 1. 빔 b의 공통 빔 패턴을 (C_θ, C_φ) 함수로 등록
register_antenna_pattern(f"ssb_{b}", make_factory(F[b]))
scene.tx_array = PlanarArray(num_rows=1, num_cols=1,
    pattern=f"ssb_{b}")
scene.rx_array = PlanarArray(1, 1, pattern="iso",
    polarization="V")
# 2. 사이트: 높이 · 방위각 · 기계 틸트 · RE당 전력
tx = Transmitter("s1", position=[x, y, h],
    orientation=[az, tilt_m, 0], power_dbm=P_RE)
# 3. 지도 (경로 전력은 비결맞음 합)
rm = RadioMapSolver()(scene, cell_size=[5, 5],
    max_depth=5, samples_per_tx=10**7)
rsrp[b] = 10*log10(rm.rss) + 30 + G_ue_dB

make_factory

patterns에 보간 함수 하나
(θ, φ) → (C_θ, C_φ)

테스트 지점 하나로 먼저 확인

반복

b = 0 … 7 반복

(약 50초) R1을 코드로 쓰면 세 덩어리입니다. 첫째, 빔 b의 공통 빔 패턴을 θ와 φ 성분을 돌려주는 함수로 만들어 이름을 붙여 등록하고, 송신 배열을 그 패턴의 소자 하나로 정합니다. 수신은 일단 등방성으로 두고 UE 이득은 나중에 더합니다. 둘째, 송신기를 실제 높이에 놓고 방위각과 기계 틸트를 orientation으로 주고, 전력은 RE 하나의 전력으로 넣습니다. 이 부분은 다음 장에서 자세히 봅니다. 셋째, radio map을 계산하고 rss를 dBm으로 바꾼 뒤 UE 이득을 더하면 빔 b의 RSRP 지도가 됩니다. 이것을 빔 개수만큼 반복합니다. 송신 배열은 장면 전체에 공통이므로, 사이트마다 e-tilt가 다르면 같은 e-tilt인 사이트끼리 묶어 따로 계산합니다. orientation 각의 순서와 틸트 부호는 버전과 좌표계에 따라 헷갈리기 쉬우니, 패턴 최대 방향을 지나는 테스트 지점 하나로 먼저 확인하는 것을 권합니다. 인자 이름은 사용하는 Sionna 버전의 문서를 확인하세요.
