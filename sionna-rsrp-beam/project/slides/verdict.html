(약 55초) 그럼 누구 말이 맞을까요. 세 가지 방법을 비교했습니다. A는 common beam weight를 Sionna의 이상적 배열에 곱하는 것입니다. TXRU 하나를 점 소자 하나로 보고 38.901 소자 패턴을 쓰면, 부배열 안쪽의 3소자 효과와 etilt가 빠지므로 세로 모양과 이득, 부엽이 틀립니다. 배열 모델이 실제와 똑같은 경우가 아니면 실측 비교에는 맞지 않습니다. B는 동료가 말한 방법으로, 같은 common beam weight를 현재 etilt의 실제 부배열 패턴 64개에 곱하는 것입니다. 이것이 실제 방송 빔입니다. C는 벤더가 이미 합성해 준 방송 빔 패턴 파일을 쓰는 것으로, 같은 데이터로 만든 것이라면 B와 같습니다. 그러니 두 의견은 대립이 아닙니다. common beam weight는 무엇을 곱할지, 부배열 패턴은 어디에 곱할지입니다. 동료가 이 과정으로 common beam weight를 만들 수 있다고 한 것도, 원하는 방송 빔 모양이 나오도록 부배열 패턴 위에서 w를 설계한다는 뜻입니다.
