# 전파 모델 쉽게 이해하기 (신입 사원용)

발표 자료 「전파 모델의 역사」를 처음 보는 분을 위한 요약본입니다. 수식은 최소한으로 줄이고 비유를 썼습니다. 더 자세한 설명과 수치는 [`qna.md`](qna.md)에 있습니다.

## 한 줄 요약

> 전파 모델은 "신호가 여기까지 얼마나 약해져서 도착할까?"를 예측하는 도구다. 통신 기술이 바뀔 때마다 묻는 질문이 바뀌었고, 그때마다 새 모델이 나왔다.

## 먼저 알아 둘 용어

| 용어 | 쉬운 뜻 |
|---|---|
| dB, dBm | 아주 큰 비율이나 전력을 다루기 쉽게 로그로 바꾼 단위. 곱셈이 덧셈이 된다. 3 dB ≈ 2배, 10 dB = 10배 |
| 경로손실 | 거리가 멀어지면서 신호가 약해지는 양. 멀어질수록 목소리가 작게 들리는 것과 같다 |
| 쉐도잉 | 건물이나 언덕 뒤 "전파 그늘"에서 신호가 더 약해지는 것 |
| 페이딩 | 여러 길로 온 신호가 겹쳐 세졌다 약해졌다를 빠르게 반복하는 것 |
| 다중경로 | 신호가 직접, 벽에 반사되어, 모서리를 돌아서 등 여러 길로 도착하는 것 |
| LOS / NLOS | 송신기가 눈에 보이는 상태(가시선) / 가려진 상태 |
| 지연 확산 | 여러 길로 온 신호가 도착하는 시간 차이의 폭. 산에서 메아리가 시간차를 두고 돌아오는 것과 비슷하다 |
| MIMO | 안테나 여러 개로 여러 데이터를 동시에 보내는 기술 |
| 레이 트레이싱 | 3D 지도 위에서 전파를 빛처럼 하나하나 추적해 계산하는 방법 |

## 슬라이드별 핵심 질문

### 02. 왜 전파 모델이 필요한가

**링크 예산이 뭔가요?**
송신기에서 수신기까지 신호의 **가계부**입니다. 얻은 것(송신 전력, 안테나 이득)은 더하고 잃은 것(경로손실)은 빼서, 마지막에 남은 수신 전력이 "연결 가능한 최소값"보다 크면 통신이 됩니다.

`수신 전력 = 송신 전력(P_tx) + 안테나 이득(G) − 경로손실(PL)`

송신 전력과 안테나는 우리가 고를 수 있지만, 경로손실은 환경이 정합니다. 이 빈칸을 채우는 것이 전파 모델입니다.

**신호가 약해지는 방식이 왜 세 가지인가요?**
규모가 다르기 때문입니다.
- **경로손실**: km 단위로 멀어지며 서서히 약해짐
- **쉐도잉**: 건물 뒤 그늘처럼 수십~수백 m 단위로 오르내림
- **페이딩**: 몇 cm만 움직여도 신호가 확 약해졌다 돌아옴

### 03. 70년의 흐름

**모델 종류가 왜 이렇게 많나요?**
크게 두 계열입니다.
- **통계 계열**: 많이 측정해서 "평균적으로 이렇다"를 식으로 만든 것. 빠르지만 특정 장소는 모릅니다.
- **결정론 계열**: 지도와 물리 법칙으로 직접 계산하는 것. 정확하지만 무겁습니다.

최근에는 두 계열을 섞는 방향입니다.

### 04. 자유공간 공식 (Friis)

**가장 기본 공식이 있는데 왜 다른 모델이 필요했나요?**
Friis 공식은 "장애물이 하나도 없는 허공"을 가정합니다. 실제 도시에는 땅, 건물, 나무가 있어서 신호가 이 공식보다 훨씬 빨리 약해집니다. 그래서 "실제로 재 보자"는 방향으로 갔습니다.

### 05. Okumura–Hata

**"닫힌 형태의 수식으로 근사했다"는 게 무슨 말인가요?**
- **Okumura**는 도쿄에서 측정한 결과를 **그래프**로 냈습니다. 값을 알려면 사람이 그래프를 읽어야 했습니다.
- **Hata**는 그 그래프 모양을 따라 하는 **계산식**을 만들었습니다. 주파수, 거리, 안테나 높이만 넣으면 바로 답이 나옵니다.

계산식이 되자 컴퓨터로 수천 개 지점을 자동 계산할 수 있게 됐습니다. 대신 측정한 범위 밖에서는 잘 맞지 않습니다.

### 06. COST 231

**왜 또 새 모델이 필요했나요?**
2세대(GSM) 시대에 두 가지가 바뀌었습니다.
- 주파수가 높아졌습니다(1.8–2 GHz). Hata 식의 범위 밖입니다.
- 기지국이 작아져 건물 지붕 근처나 아래로 내려왔습니다.

그래서 건물 높이, 도로 폭 같은 **도시 구조**를 입력으로 받는 모델이 나왔습니다.

### 07. 확률적 채널 모델

**TDL이 뭔가요?**
메아리 몇 개를 흉내 내는 장치입니다. "첫 신호, 조금 뒤 두 번째, 더 뒤 세 번째…"처럼 **도착 시간과 평균 세기는 표로 정해 두고**, 각 신호가 세졌다 약해졌다 하는 것만 무작위로 만듭니다.

**클러스터가 뭔가요?**
**같은 물체에서 튕겨 온 신호 묶음**입니다. 한 건물 벽에서 반사된 신호들은 이동 거리가 비슷해서 거의 같은 시간에 함께 도착합니다. 실제 채널은 이런 묶음 몇 개로 이루어져 있습니다.

### 08. MIMO와 GSCM

**"안테나 사이의 상관에 성능이 달려 있다"는 무슨 뜻인가요?**
여기서 "상관"은 **안테나마다 받는 신호가 얼마나 비슷한가**입니다. 두 귀를 떠올려 보세요. 두 귀가 똑같이 들으면 소리의 방향을 구분할 수 없고, 다르게 들어야 구분할 수 있습니다. MIMO도 안테나마다 받는 신호가 서로 달라야 여러 데이터를 나눠 받을 수 있습니다. 이것은 신호가 **어느 방향에서 오는지**에 달려 있어서, 방향 정보가 모델에 필요해졌습니다.

**"채널과 안테나를 분리했다"는 건 무슨 뜻인가요?**
공연장에 비유하면 이렇습니다.
- **채널**: 공연장 안에서 어떤 소리가 어느 방향에서 언제 오는지
- **안테나**: 그 소리를 듣는 마이크

GSCM은 먼저 "어느 방향에서 어떤 신호가 오는가"의 목록을 만들고, 어떤 마이크(안테나 배열)로 들을지는 나중에 골라 계산합니다. 그래서 같은 채널 모델로 2개짜리 안테나도, 64개짜리 안테나도 평가할 수 있습니다.

**그 전에는 안테나를 분리하지 않았나요?**
했습니다. 다만 "안테나 이득"이라는 **숫자 하나만** 따로 뺐습니다. 이 방식은 안테나가 모든 방향을 똑같이 들을 때만 정확합니다. 특정 방향을 잘 듣는 안테나나 여러 개짜리 배열에서는 방향 정보가 있어야 하고, GSCM이 그 범위를 넓혔습니다.

**UMa, UMi, InH는 뭔가요? 특정 지역을 뜻하나요?**
특정 도시가 아니라 **환경의 종류**입니다. 표준 시험을 위한 "세트장"이라고 생각하면 됩니다.

| 이름 | 뜻 | 떠올리면 되는 장면 |
|---|---|---|
| UMa | 도심 매크로 | 빌딩 옥상 기지국이 넓은 도심을 커버 |
| UMi | 도심 마이크로 | 길가의 작은 기지국이 거리 하나를 커버 |
| InH | 실내 핫스팟 | 사무실 천장의 실내 기지국 |

여러 나라의 측정 데이터를 종류별로 모아 평균적인 특성을 만들었기 때문에, 어느 회사든 같은 조건에서 기술을 비교할 수 있습니다.

### 09. 레이 트레이싱

**어떻게 동작하나요?**
게임 그래픽에서 빛을 추적하는 것과 비슷합니다. 3D 지도 위에서 전파를 직선으로 쏘고, 벽에 닿으면 반사시키고 모서리에서는 꺾어서, 수신기까지 가는 길을 모두 찾습니다. 그 결과 "이 장소에서는 이렇게 들어온다"가 나옵니다.

**단점은요?**
지도나 건물 재질 정보가 틀리면 결과도 틀립니다. 넓은 지역은 계산도 오래 걸립니다.

### 10. 세 계열 비교

**그래서 어떤 모델이 제일 좋은가요?**
정답은 없고, **목적에 따라** 고릅니다.
- 대략적인 커버리지를 빨리 보고 싶다 → 경험식 (Okumura–Hata 등)
- 여러 기술을 공정하게 비교하고 싶다 → 표준 통계 모델 (3GPP 38.901)
- 특정 장소를 정확히 알고 싶다 → 레이 트레이싱

### 11. 최근 흐름

**요즘은 어떤 방향인가요?**
**섞어 쓰는** 방향입니다.
- 큰 길은 지도로 계산하고, 세부는 통계로 채웁니다(하이브리드).
- AI가 지도를 보고 전파 세기 지도를 순식간에 그려 줍니다.
- 실제 측정값에 맞춰 레이 트레이싱 설정을 자동으로 보정합니다.

### 12. 정리

**이 발표에서 기억할 한 가지는?**
**질문이 바뀌면 모델이 바뀐다.** "얼마나 멀리 가나?" → "이 도시에서는?" → "작은 셀에서는?" → "메아리는?" → "안테나가 여러 개면?" → "바로 이 장소에서는?"으로 질문이 바뀌어 왔고, 각 질문에 답한 모델이 그 시대의 대표 모델이 됐습니다.
