# 드라이브 테스트 비교 결과 읽기: Breakdown 화면

드라이브 테스트 실측과 시뮬레이션을 비교한 결과를 읽는 법을 정리한 자료입니다. 비교 요약의 Breakdown 화면(한국어 화면: 경향)을 다룹니다. 이 화면은 판정 숫자 de-biased RMSE를 **거리 경향 · 진폭 · 패턴** 세 갈래로 나눠, 무엇부터 고칠지 알려 주는 진단 화면입니다.

다루는 내용은 다음과 같습니다.

- 정의(층 T0 · T1 · T2, 칸, 오차 부호)와 화면 배치
- 숫자 타일 다섯(판정 · 기록 · 진단)과 거리 경향을 먼저 떼는 이유
- 보충: 국소 변동이란 무엇인지, 진단 셋(α · r · c₁)을 가상 칸 6개로 손 계산
- 유효 표본 수(n_eff)
- Error breakdown 띠와 고칠 순서
- 세 그림(Taylor diagram · Residual vs distance · Shape)
- 예시 해석과 한계

참고할 점:
- **원본:** 모든 정의 · 식 · 화면 문구 · 예시 수치는 Breakdown 화면 설명서(§0~§9)를 그대로 옮긴 것입니다. 설명서에 없는 것은 아래처럼 예시로 표시했습니다.
- **예시 숫자의 불일치(14쪽):** 스크린샷 값 α 1.21, r 0.62를 설명서의 식에 넣으면 진폭 · 패턴 몫의 비가 맞지 않습니다.
  - 식: 진폭 (σb − σa)², 패턴 2σaσb(1 − r)
  - 진폭 / 패턴 = (α − 1)² / (2α(1 − r)) ≈ 0.048 → 패턴 43%라면 진폭은 약 2%여야 합니다.
  - 거꾸로 띠의 28% : 43%를 맞추려면 α가 약 2.0이어야 합니다.
  - 스크린샷의 출처(목업 여부)나 계산을 확인해 주세요. 슬라이드 각주에도 같은 내용을 적었습니다.
  - Bias 몫 9%는 띠의 bias가 평균(약 2.1 dB) 기준이면 de-biased RMSE 6.8 dB와 맞습니다. 타일의 Bias +2.4 dB는 중앙값 기준입니다.
- **가상 예(6 · 7쪽, 보충):** 칸 6개(100 m ~ 1 km)에 실측 −35 · 시뮬 −31 dB/decade 직선과 국소 변동(실측 +4 −6 +3 −5 +6 −2, 시뮬 +2 −3 +1 −2 +3 −1 dB)을 더해 만든 값입니다. 각자 회귀하면 기울기 −35.3 · −31.0 dB/decade, 국소 σ 4.58 · 2.16 dB(모표준편차), α 0.47, r 0.99, c₁ +4.3 dB/decade입니다. 띠의 세 몫(거리 2.2 · 진폭 5.9 · 패턴 0.13 dB²)의 합이 칸 오차 분산 8.1 dB²와 정확히 같음을 생성기에서 확인했습니다. 실제 데이터가 아니고, 칸 6개로는 구간을 낼 수 없어 95% 구간은 생략했습니다.
- **가정 예(8쪽):** 로그 거리 분산 0.2133(50 m ~ 2 km에 고르게), 기울기 30 / 31.5 dB/decade, 국소 σ 6 / 4 dB로 정했습니다. 설명서의 합성 데이터 결과(전역 α 1.0 · 국소 α 0.66)와 같은 현상을 보여 주려는 값입니다.
- **예시 그림(9 · 12 · 13쪽):** 개념 그림이며 실제 비교 데이터가 아닙니다.
  - 9쪽 격자는 자기상관을 보여 주는 개념도입니다.
  - 12쪽의 ○ 전(예시) 위치와 reach 선은 그림 설명용입니다.
  - 13쪽의 점과 분포는 합성 데이터입니다.
- **n_eff 역산(9쪽):** 1,204 → 312면 φa·φb ≈ 0.59입니다. 설명서의 근사식에서 역산했습니다.
- **경로손실 지수(5 · 14쪽):** c₁ = 10 · Δn이므로 +4.2 dB/decade는 Δn ≈ 0.42입니다. 오차 = 시뮬 − 실측이 거리와 함께 커지므로 시뮬의 거리 감쇠가 완만합니다.
- **고칠 순서(11쪽):** 몫과 원인의 대응은 설명서대로 진단의 출발점입니다. “좌표가 조금만 어긋나도 패턴 몫부터 커진다”는 일반적인 경향으로 덧붙인 설명입니다.
