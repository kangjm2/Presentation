편파는 세로 패턴을 몇 도 기울여, 몇 개 겹치느냐다

"V"

ζ = 0°
단일 편파

"H"

ζ = 90°
단일 편파

"VH"

ζ = 0°, 90°
이중 편파

"cross"

ζ = −45°, +45°
이중 편파 · 기지국 표준

만드는 방법

세로 편파 패턴 하나를 기울기 ζ만큼 돌려서 쓴다 — 이중 편파는 같은 위치에 두 개를 겹친 것

개수 세기

2×4, "cross"
array_size = 8 # 위치
num_ant = 16 # 출력 TA

왜 중요한가

이중 편파는 같은 자리에서 독립 경로 2개 → MIMO 계층 · 다이버시티

Sionna RT 소스: register_polarization("V", [0]) · ("H", [π/2]) · ("VH", [0, π/2]) · ("cross", [−π/4, π/4]) · AntennaArray.num_ant

(약 55초) 두 번째 파라미터는 polarization, 편파입니다. 편파는 전기장이 어느 방향으로 떨리는지입니다. Sionna는 세로 편파 패턴 하나를 기울기 각 ζ만큼 돌려서 다른 편파를 만듭니다. V는 0도, H는 90도로 단일 편파이고, VH는 0도와 90도, cross는 −45도와 +45도 두 개를 같은 위치에 겹친 이중 편파입니다. 기지국은 보통 cross를 씁니다. 개수를 셀 때 주의할 점이 있습니다. 2행 4열에 cross를 쓰면 소자 위치는 8개지만 안테나는 16개로 셉니다. array_size는 위치 수, num_ant는 편파까지 센 수이고, 출력 텐서의 안테나 차원은 num_ant입니다. 이중 편파가 중요한 이유는 같은 자리에서 서로 거의 독립인 두 경로를 얻을 수 있어서, 배열을 키우지 않고도 MIMO 계층이나 다이버시티를 얻기 때문입니다.
