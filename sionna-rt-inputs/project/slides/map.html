Sionna RT 1.x · 2.x API 기준 · CIR · CFR · 탭 변환은 Sionna 채널 세미나 참조

02 / 12

(약 50초) 먼저 전체 지도입니다. Sionna RT에 넣는 것은 크게 여섯 가지입니다. 건물과 지형 같은 장면, 그 장면의 각 물체에 붙는 재질, 송수신 안테나 배열, 송수신기의 위치와 방향, 주파수, 그리고 솔버 설정입니다. 이걸 PathSolver에 넣으면 경로마다 이득, 지연, 각도, 도플러가 나오고, 이 경로에서 cir, cfr, taps 함수로 CIR, CFR, FIR 탭을 만듭니다. 이 부분은 지난 Sionna 채널 세미나에서 다뤘습니다. 여섯 입력은 역할로 묶으면 이해가 쉽습니다. 장면과 재질은 환경이라 결과가 얼마나 정확할 수 있는지 상한을 정하고, 안테나와 송수신기는 링크라 출력 텐서의 모양을 정하며, 주파수와 솔버 설정은 조건이라 재질 값과 계산량, 재현성을 정합니다.
