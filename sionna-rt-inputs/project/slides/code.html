여섯 입력이 코드 열한 줄에 들어간다

①

scene = rt.load_scene(rt.scene.munich, merge_shapes=True)

②

scene.get("building_1").radio_material = mat # 필요한 물체만

⑤

scene.frequency = 3.5e9

③

scene.tx_array = rt.PlanarArray(num_rows=2, num_cols=4, pattern="tr38901", polarization="cross")

③

scene.rx_array = rt.PlanarArray(num_rows=1, num_cols=2, pattern="iso", polarization="V")

④

tx = rt.Transmitter("tx", position=[8.5, 21, 30], power_dbm=44)

④

rx = rt.Receiver("rx", position=[45, 90, 1.5], velocity=[3, 0, 0])

④

scene.add([tx, rx]); tx.look_at(rx)

⑥

paths = rt.PathSolver()(scene, max_depth=5, diffuse_reflection=True)

→

a, tau = paths.cir(sampling_frequency=1e4, num_time_steps=14, out_type="numpy")

→

h = paths.cfr(frequencies=rt.subcarrier_frequencies(1024, 30e3), out_type="numpy")

import sionna.rt as rt 기준 · mat은 4쪽에서 만든 재질 · 좌표 · 물체 이름은 예시 (실제 장면에 맞게)

(약 55초) 지금까지 본 여섯 입력이 코드에서는 이렇게 들어갑니다. 왼쪽 번호가 입력 번호입니다. 장면을 불러오고, 필요한 물체에 재질을 지정하고, 주파수를 정합니다. 그다음 송신 배열과 수신 배열을 장면에 설정합니다. 여기서는 송신 2행 4열 교차 편파, 수신 2소자 수직 편파입니다. 송신기와 수신기를 만들고, 수신기에는 초속 3미터 속도를 줘서 도플러가 생기게 하고, 장면에 넣은 뒤 송신기가 수신기를 바라보게 합니다. 마지막으로 PathSolver를 반사 5차, 확산 산란을 켠 설정으로 호출하면 경로가 나옵니다. 경로에서 cir을 부르면 시간 14단계의 CIR이, cfr을 부르면 부반송파 1024개의 주파수 응답이 나옵니다. 좌표와 물체 이름은 예시이고, 함수 이름과 인자는 사용하는 버전의 문서로 꼭 확인하세요.
