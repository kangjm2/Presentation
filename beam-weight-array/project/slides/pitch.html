④ 세로 피치 d_v · 피팅

세로 위상 간격과 E-tilt로 포트 세로 피치를 푼다

Δψ_행 = 2π · d_v · sin(E-tilt) → d_v = (Δψ_행 / 360° + m) / sin(E-tilt)
예: (106.7° / 360° + 0) / sin 6° = 2.84 λ

켤레 (conjugate) 먼저

w를 그대로 쓰느냐 w*로 쓰느냐에 따라 Δψ의 부호가 뒤집혀 빔이 위 또는 아래를 향한다 → 빔이 아래로 향하는 쪽을 골라 부호를 정한 뒤 d_v를 푼다 (데이터로 결정)

(약 55초) 세로 위상 간격이 나오면 포트의 세로 피치를 풀 수 있습니다. 빔을 E-tilt만큼 숙이려면 위아래 포트 사이 위상 차가 2파이 곱하기 피치 곱하기 사인 E-tilt여야 합니다. 거꾸로 풀면 피치는 위상 차를 360도로 나눈 값에 정수 m을 더하고, 사인 E-tilt로 나눈 값입니다. 예시의 106.7도와 E-tilt 6도를 넣으면 2.84 파장이 나옵니다. 정수 m이 붙는 이유는 위상이 360도마다 같아 보이기 때문입니다. 그래서 해가 1 나누기 사인 6도, 약 9.6 파장 간격으로 여러 개 있고, CF는 0.5 파장 이상인 가장 작은 해를 고릅니다. 샘플 파일의 결과 2.84 파장은 제품팀 값 0.712 곱하기 4, 2.848과 맞았습니다. 하나 더, 웨이트를 그대로 쓰느냐 켤레로 쓰느냐에 따라 위상 차의 부호가 뒤집혀 빔이 위나 아래를 향합니다. CF는 빔이 아래로 향하는 쪽을 골라 부호를 먼저 정합니다.
