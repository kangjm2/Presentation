왜 그런가

서브어레이 널 자리는 안테나 안의 고정 위상(서브 틸트)이 정하고, 그레이팅 로브 자리는 포트 웨이트(빔 틸트)가 정한다 → 둘이 다르면 널이 비켜 간다

의미

14쪽의 “−44 dB 이하”는 서브 틸트 = E-tilt 가정의 결과 · 웨이트로 더 숙이는 빔이나 실제 서브 틸트가 다른 패널이면 위아래 간섭이 커진다 → 실제 서브어레이 자료가 필요한 이유

(약 50초) 앞쪽에서 서브어레이의 널이 그레이팅 로브를 정확히 누른다고 했는데, 여기에는 조건이 있습니다. 서브어레이 널의 자리는 안테나 안에 고정된 위상, 즉 서브 틸트가 정하고, 그레이팅 로브의 자리는 포트 웨이트로 만든 빔 틸트가 정합니다. 둘이 같은 6도면 왼쪽 남색 선처럼 그레이팅 로브가 널에 묻힙니다. 그런데 웨이트로 빔을 10도까지 숙이면 널이 비켜 가서, 주황 점선처럼 위아래에 그레이팅 로브가 -12 dB, -14 dB로 살아나고 주엽도 0.5 dB 줄어듭니다. 그래서 14쪽의 마이너스 44 dB 이하라는 결과는 서브 틸트가 선언 E-tilt와 같다는 가정에서 나온 것입니다. 실제 서브어레이 자료를 받아야 위아래 간섭을 믿을 수 있는 이유가 여기 있습니다.
