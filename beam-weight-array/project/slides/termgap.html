식 빔 패턴 = 포트 패턴(폭이 정함) × 어레이 팩터(간격과 웨이트가 정함)

간격이 틀리면 → 방향이 틀어진다

웨이트의 위상 차는 고정 · 실제 0.541 λ로 설계한 빔을 0.5 λ로 읽으면
7.5°→8.1° · 22.5°→24.5° · 37.5°→41.2° · 52.5°→59.1° · 가장자리일수록 크다

폭이 틀리면 → 세기 분포가 틀어진다

방향은 그대로 · 옆으로 돌린 빔은 그 방향의 포트 패턴만큼 약해진다 → 가장자리 빔이 너무 약하거나 세게

왜 “소자” 수평폭인가

서브어레이는 세로로만 묶여 수평 모양을 안 바꾼다 → 소자 수평폭 = 포트 수평폭 · 수직은 서브어레이가 더 좁힌다

방향 계산: sin(방위) = Δψ ÷ (2π · d_h) → asin(sin 37.5° × 0.541 / 0.5) = 41.2° (생성기 계산)

(약 55초) 보충으로, 헷갈리기 쉬운 두 종류의 값을 나란히 놓겠습니다. 가로 간격과 세로 피치는 이웃 포트 중심 사이의 거리이고 단위는 파장입니다. 소자 수평폭과 수직폭은 포트 하나가 절반 세기로 덮는 각도이고 단위는 도입니다. 무대 조명으로 비유하면 간격은 조명과 조명 사이 거리, 폭은 조명 하나가 비추는 원뿔의 각도입니다. 둘은 식의 다른 항에 들어갑니다. 간격은 웨이트와 함께 어레이 팩터를 정해 빔의 방향과 날카로움, 그레이팅 로브를 정하고, 폭은 포트 패턴, 즉 모든 빔에 곱해지는 덮개를 정합니다. 그래서 틀렸을 때의 증상도 다릅니다. 간격이 틀리면 빔 방향이 틀어집니다. 실제 간격 0.541 파장으로 37.5도를 노린 웨이트를 0.5 파장으로 읽으면 약 41.2도를 향하게 됩니다. 폭이 틀리면 방향은 그대로지만 옆으로 돌린 빔의 세기가 틀어집니다. 참고로 서브어레이는 세로로만 묶여 있어 소자 수평폭이 곧 포트의 수평폭입니다.
