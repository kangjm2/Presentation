# 단말 KPI가 만들어지는 과정

드라이브 테스트 리포트의 단말 KPI(RSRP · SINR · CQI · MCS · BLER · 처리량 · 성공률 · 지연)가 *어떻게 숫자가 되는지* 정리한 자료입니다. KPI마다 무선 신호 → 칩셋 처리 → 진단 로그 → DM 툴 → 후처리의 흐름을 같은 틀로 따라가고, 숫자 예로 집계 방법의 차이를 보여 줍니다. 16장이고, 슬라이드마다 발표자 노트가 있습니다.

KPI의 *의미*와 *최적화 활용*(DU 파라미터 · RU 배치)은 [`ue-kpi`](../ue-kpi/) 덱이 다룹니다. 이 덱은 그 앞 단계, 즉 KPI 값이 어디서 와서 어떻게 계산되는지에 집중합니다.

- **발표용 뷰어 (내비게이션 포함):** https://claude.ai/artifact/SjjPG1zwL2JxDefR6pBtQe, 또는 로컬에서 `presentation.html`을 브라우저로 열기
- 편집용 Slides 덱: https://claude.ai/artifact/ERA8jz14FrWBV3Z9Z2B1yD
- 두 링크 모두 비공개 — 다른 사람에게 보여주려면 페이지의 Share 메뉴에서 공유
- 예상 질문과 답변: [`qna.md`](qna.md) (슬라이드별)
- 뷰어 조작법은 [`../propagation-models/README.md`](../propagation-models/README.md#뷰어-조작)와 같습니다. 슬라이드를 고친 뒤 리포 루트에서 `python3 viewer/build.py ue-kpi-pipeline`로 뷰어를 다시 만듭니다.
- 관련 덱: [`ue-kpi`](../ue-kpi/) (KPI의 의미와 활용) · [`ss-rsrp`](../ss-rsrp/) (RSRP 측정 사슬) · [`du-ue-flow`](../du-ue-flow/) (DU와 단말의 데이터 흐름) · [`sionna-rsrp-beam`](../sionna-rsrp-beam/) (실측과 시뮬레이션 비교)

10분 안에 맞추려면 4쪽(층과 로그) · 6쪽(RSRQ · SINR) · 15쪽(망 KPI 비교)을 백업으로 돌리세요(약 10분 30초). 14쪽(자주 틀리는 점)까지 빼면 약 9분 40초입니다. 14쪽의 내용은 각 KPI 장의 주의 카드에 흩어져 있어 빼도 흐름이 끊기지 않습니다.

직접 채워 넣을 부분:
- 표지의 `[발표자] · [소속] · [날짜]`

참고할 점:
- **예시 값:** 5쪽(RSRP 빔별 값과 L3 필터), 8쪽(슬롯 10개의 MCS · RB · 레이어), 9쪽(TB 10개), 10쪽(층별 처리량), 12쪽(시간 값)은 설명용으로 만든 예입니다. 계산은 맞지만 실제 측정값이 아닙니다.
- **RSRP 숫자 따라가기(5쪽):** 상위 2빔 선형 평균(−95.4, −96.6 → −96.0 dBm), L3 필터 a = ½(k = 4, dB 값에 적용: −94.4와 −96.0 → −95.2 dBm), 보고 RSRP_61(−96 ≤ x < −95 dBm, TS 38.133 매핑)입니다. 빔 통합 문턱 · 개수는 망 설정마다 다릅니다.
- **DM 툴:** XCAL · Nemo · TEMS 등 툴마다 필드 이름, L1 / L3 중 어떤 값을 보여 주는지, 사건 판정 규칙이 다릅니다. 칩셋 진단 로그의 형식과 주기도 칩셋마다 다릅니다. 실제 툴의 정의서와 한 번 맞춰 보세요.
- **이벤트 정의(11쪽):** SA 기준입니다. NSA(EN-DC)에서는 LTE RRC 메시지(SgNB 추가 등)로 NR 접속을 판정합니다. 재시도 · 테스트 스크립트 단위는 사업자 기준을 따르세요.
- **집계 표(13쪽):** 일반적인 원칙입니다. 사업자 KPI 정의서가 다르게 정하면 그쪽을 따르세요.

## 출처

- 3GPP TS 38.215 (SS-RSRP · SS-RSRQ · SS-SINR · CSI-RS 측정 정의)
- 3GPP TS 38.133 (측정 보고 범위와 매핑: RSRP −156 ~ −31 dBm · 1 dB, RSRQ −43 ~ 20 dB · 0.5 dB, SINR −23 ~ 40 dB · 0.5 dB)
- 3GPP TS 38.331 (측정 설정 · 빔 통합 · L3 필터 5.5.3, RRCSetup · RRCReconfiguration · reconfigurationWithSync, RLF)
- 3GPP TS 38.214 (CQI 정의 5.2.2, MCS 표 5.1.3, CSI 보고)
- 3GPP TS 38.212 7.3.1 (DCI 형식 0_1 · 1_1 필드) · TS 38.213 9 (HARQ-ACK 보고)
- 3GPP TS 38.300 (NR 프로토콜 구조) · TS 38.306 4.1.2 (최대 전송률 근사)
- 3GPP TS 28.552 (5G 성능 측정 항목, 망 카운터)
