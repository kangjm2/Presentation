그리는 법 · 계산은 다섯 줄

짝지은 dB 값만 있으면 바로 그린다

import numpy as np, matplotlib.pyplot as plt
r, f = meas_db, sim_db # 같은 구역 · 같은 순서의 짝
bias = f.mean() - r.mean()
sr, sf = r.std(), f.std()
R = np.corrcoef(f, r)[0, 1]
E = np.std(f - r) # 중심 RMS 차이 E′
ax = plt.subplot(projection="polar")
ax.set_thetalim(0, np.pi / 2) # 사분원
ax.plot(0, sr, "k*", ms=14) # ★ 실측
ax.plot(np.arccos(R), sf, "o") # 각도 = arccos R, 반지름 = σ
ax.annotate(f"{bias:+.1f} dB", (np.arccos(R), sf)) # 바이어스는 글자로

검산

E**2 ≈ sf**2 + sr**2 − 2*sf*sr*R
(std는 모두 같은 ddof로)

눈금 · 등고선

R 눈금은 각도 arccos R 위치에
E′ 등고선은 ★ 중심 원으로 직접 그린다

패키지

Python: SkillMetrics 등
R: plotrix · openair의 TaylorDiagram

numpy · matplotlib 극좌표 축 · 패키지마다 기본값(정규화 여부 · ddof)이 다르니 확인

(약 45초) 그리는 법은 간단합니다. 같은 구역끼리 짝지은 실측과 시뮬의 dB 값이 있으면, 바이어스, 두 표준편차, 상관, 그리고 오차의 표준편차인 E′를 다섯 줄로 계산합니다. 그림은 matplotlib의 극좌표 축을 사분원으로 제한하고, 실측은 각도 0, 반지름 σ_r에 별로, 시뮬은 각도 arccos R, 반지름 σ_f에 점으로 찍습니다. 바이어스는 그림에 안 나오니 점 옆에 글자로 적습니다. 계산이 맞는지는 코사인 법칙으로 검산할 수 있는데, 표준편차를 모두 같은 방식으로 계산해야 정확히 맞습니다. 눈금과 등고선을 직접 그리기 번거로우면 Python의 SkillMetrics, R의 plotrix나 openair 같은 패키지를 쓰면 됩니다. 패키지마다 정규화 여부 같은 기본값이 다르니 확인하세요.
