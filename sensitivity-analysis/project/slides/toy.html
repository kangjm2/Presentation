직접 계산할 수 있는 작은 RSRP 모형

RSRP = 10·log10( 직접 + 반사 ) [mW 합]
직접 = P0 + ΔP + G − PL(d) − J(ν)
반사 = P0 + ΔP + G − PL(d′) − Γ(εr) − 6
G = 17 − min(12(Δθ/10°)² + 12(Δφ/65°)², 30)
PL = 28 + 22·log10 d + 20·log10 3.5
J = 6.9 + 20·log10(√((ν−0.1)²+1) + ν − 0.1)

(약 55초) 실제 레이 트레이싱은 한 번 돌리는 데 시간이 걸려서, 오늘은 손으로 계산할 수 있는 장난감 모형을 실험대로 씁니다. RSRP는 직접 경로와 벽 반사 경로의 전력 합입니다. 안테나 이득은 3GPP TR 38.901 소자 패턴과 같은 모양인데, 소자의 수직 빔폭 65도 대신 패널 빔을 흉내 내 10도로 좁혔습니다. 거리 감쇠는 38.901 UMa 가시선의 첫 식을, 지붕 회절은 ITU-R P.526의 칼날 회절 근사식을 빌렸고, 반사는 유전율로 프레넬 반사 계수를 계산합니다. 오른쪽 곡선을 보면 약 190 m까지는 지붕 위로 RU가 보이고, 그 뒤로는 직접 경로가 회절로 빠르게 약해져 반사가 주가 됩니다. 대표 칸은 160 m로, 가림선이 지붕 바로 위를 지나는 자리입니다. 회절 손실이 막 켜지기 직전이라, 뒤에서 보듯 여기서 하나씩 바꿔 보는 방법이 잘 속습니다.
