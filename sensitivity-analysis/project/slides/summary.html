돌리기 전에, 어떤 손잡이가 붙어 있는지부터

OAT는 한 점의 기울기

명목점에서 회절 0.0 dB → 얽히면 순위가 바뀐다
범위 전체를 함께 흔든다

Morris → Sobol

Morris r(k+1)로 거르고
Sobol Sᵢ · STᵢ로 분산 몫을 잰다 · 비용 N(k+2)

칸마다 다르다

가까운 칸 좌표 · 전이 구간 건물 높이
먼 칸 전력 · 방위각 · 틸트

σ_sim = 칸별 분포의 폭

예시 0.9~4.8 dB · 수치 잡음과 입력 불확실성을
나눠 재야 도달점에 쓸 수 있다

보정 대상 고르기

STᵢ ≈ 0 고정 · 재야 할 것은 재고 · 손잡이는
구별되는 칸 조합으로 함께 (틸트 ↔ 전력)

다음 단계: [대상 셀]에서 입력 범위를 실제 값으로 채우고, Morris 200회 → 남은 입력 Sobol(또는 대리 모델)로 칸별 STᵢ 지도와 σ_sim을 만든다

관련 자료: dt-breakdown (도달점 · σ_sim) · sim-real-alignment · coord-registration

(약 40초) 정리하겠습니다. 하나씩 바꿔 보기는 명목점 한 곳의 기울기라, 입력끼리 얽혀 있으면 순위를 잘못 알려 줍니다. 범위 전체를 함께 흔드는 전역 방법이 필요하고, 싼 Morris로 먼저 거른 뒤 Sobol 지수로 분산의 몫을 잽니다. 어떤 입력이 흔드는지는 칸마다 다릅니다. 몬테카를로로 얻는 칸별 분포의 폭이 σ_sim이고, 오늘 예시에서는 0.9에서 4.8 dB였습니다. 다만 수치 잡음과 입력 불확실성을 나눠 재야 Breakdown의 도달점에 쓸 수 있습니다. 보정할 것은 전체 지수가 크고 데이터로 구별되는 손잡이이고, 0에 가까운 것은 고정합니다. 다음 단계로 대상 셀의 입력 범위를 실제 값으로 채워 칸별 지도와 σ_sim을 만들어 보겠습니다. 감사합니다.
