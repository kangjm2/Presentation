# 공변량: 잔차는 어느 요인 탓인가

Gap Lab 갈래 ②(정합)의 바탕인 **공변량**을 설명하는 자료입니다. 공변량은 3 m 칸마다 붙는 “그 칸의 사정”입니다(송신기까지 거리, 시야, 수목 통과 길이, 안테나 정면에서 벗어난 각 등). 실측 잔차(실측 − 시뮬)가 어떤 요인이 작용하는 칸에 몰려 있으면, 그 요인이 차이를 만든다는 **정황**이 됩니다.

원문은 공변량 설명 문서(주제 코드 `LAB`, 초안 2026-11-03)입니다. **새 결정은 없고**, 이미 정한 내용(experiment-ledger §2 · §3-4)을 처음 읽는 사람의 순서로 옮겼습니다.

다루는 내용은 다음과 같습니다.

- 왜 필요한가: 잔차 하나에는 모든 요인이 섞여 있고, 요인마다 흔적이 남는 칸이 다르다
- 무엇을 공변량으로 두나
  - 조건 셋: 칸마다 값이 있다 · 요인이 작용하는 정도를 나타낸다 · 실측을 보기 전에 정해진다
  - 목록 9개: `los` · `path_kind` · `foliage_m` · `off_az`/`off_el` · 거리 · `blocker_id` · `n_paths` · 이웃 칸 잔차(예외) · σ_pos
- 통제 공변량 거리: 같은 거리 띠 안에서 맞댄다
- 분석 다섯 단계
  - 짝 맞추기 → 편향 빼기 → 층 나누기 → 맞대기 → 구간과 판정
  - 유효 표본 수(n_eff)로 구간을 낸다
  - 판정: `supported` · `ruled_out` · `not_distinguished`
- 손으로 따라가는 예(−3.8 dB · −1.5 dB), 세 갈래 사다리, 함정 다섯, 지금 상태

참고할 점:
- **원문 그대로 옮긴 것:** 공변량 정의 · 조건 · 목록(2쪽, 4 · 5쪽), 다섯 단계(7쪽), 판정(9쪽), 세 갈래(12쪽), 함정(13쪽), 지금 상태(14쪽). 표의 요인 코드(`F-…`)와 질문 번호(`Q-AM-88` · `Q-CAL-31` · `Q-LAB-5`)도 원문 그대로입니다.
- **손으로 따라가는 예(10 · 11쪽):** 원문 §3-4의 설명용 숫자이고 실측이 아닙니다. 생성기에서 다시 계산해 원문과 같음을 확인했습니다.
  - 중앙값의 표준오차 ≈ 1.2533 · σ / √n_eff(정규 근사)에서 1.144 · 0.661 dB, 차이의 표준오차 1.321 dB가 나옵니다.
  - 그래서 구간은 [−6.39, −1.21] dB입니다.
  - 칸 수로 세면 [−2.32, −0.68], 유효 표본으로 세면 [−4.09, +1.09]입니다.
  - 10쪽 상자 그림은 그 중앙값 · σ로 그린 정규 분포의 사분위 · 5~95% 범위입니다.
- **예시 시뮬레이션(3 · 6쪽):** 원문에 없는 설명용 그림입니다.
  - 3쪽: 3 m 칸 1,200개(3.6 km) 주행 경로에 상관거리 30 m · σ 5 dB 잔차와 수목 구간 −3.8 dB를 심었습니다. 지도 색은 15칸 이동 평균입니다.
  - 무작위 표본 하나라서 두 층의 중앙값 차이(약 −3.9 dB)는 심은 값과 비슷하지만 같지는 않습니다. 대표적인 표본을 골랐습니다(시드 27).
  - 6쪽: 수목 칸이 먼 곳에 많고 잔차에 거리 기울기(−0.8 dB/100 m)가 있을 때, 그냥 비교(약 −2.8 dB)와 거리 띠마다 비교(약 −1.7 dB, 심은 값 −1.5 dB)가 어떻게 다른지 보여 줍니다.
- **판정 그림(9쪽):** 막대 위치는 개념 설명용입니다. ε은 아직 정하지 않았습니다(`Q-CAL-31`).
