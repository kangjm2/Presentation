# 단말 안테나는 움직인다

최신 스마트폰은 안테나를 여러 개 갖고, 사용 형태와 수신 상태에 따라 쓰는 안테나를 바꾸거나 조정합니다. 이 자료는 그 방식과, DM 툴로 KPI를 모을 때 고려할 점을 정리합니다.

단말의 방식은 여섯 가지로 나눠 다룹니다.

- 수신 다이버시티
- 송신 안테나 전환과 튜닝
- SRS 안테나 스위칭
- 근접 센서와 출력 제한
- 안테나 · 레이어 줄이기
- mmWave 모듈 전환

수집 쪽은 기록 항목, 시험 조건, 시뮬레이션과 비교하는 법으로 묶었습니다. 13장이고, 슬라이드마다 발표자 노트가 있습니다.

참고할 점:
- **안테나 배치(2 · 5쪽):** 개념 그림입니다. 실제 안테나 위치와 역할(어느 안테나가 송신하는지)은 단말 모델마다 다릅니다.
- **브랜치 예시(4쪽):** −92 · −97 · −101 · −95 dBm은 설명용 값입니다. 선형 평균은 −95.1 dBm입니다. TS 38.215는 “보고 값 ≥ 어느 개별 브랜치 값”이라는 하한만 정하고, 실제로 어떻게 합칠지는 칩셋 구현입니다.
- **4Rx 요구(4쪽):** TS 38.101-1이 일부 대역(예: n41 · n77 · n78 · n79)에 수신 안테나 4개를 기본 요구로 둡니다. 대역 목록과 예외는 규격 버전으로 확인하세요.
- **송신 전환 · 튜닝 · 그립 감지(3 · 5쪽):** 제조사 · 칩셋 구현입니다. 근거는 공개 특허의 설명이며, 실제 출시 단말의 동작을 보증하지 않습니다.
- **출력 제한(7쪽):** SAR · MPE 한도와 시간 평균 방식은 각국 규제와 제조사에 따라 다릅니다. FR2의 MPE 보고는 TS 38.321 PHR MAC CE의 MPE 필드(Rel-16)입니다.
- **안테나 · 레이어 줄이기(8쪽):** UE 보조 정보에는 최대 MIMO 레이어 · 대역폭 · 반송파 수의 선호와 과열 정보가 있습니다. 이것이 수신 안테나를 실제로 끄는 것과 어떻게 연결되는지는 칩셋 구현입니다.
- **mmWave(9쪽):** 손 가림 20~25 dB는 특허 · 연구의 보고값입니다. 그래프는 개념 예입니다.
- **차량 손실(12쪽):** TR 38.901 7.4.3.2의 기본값(평균 9 dB, 표준편차 5 dB)입니다.

## 출처

규격
- 3GPP TS 38.215 5.1.1: SS-RSRP 정의, 수신 다이버시티 시 보고 규칙
- 3GPP TS 38.101-1 · 38.101-2: 단말 RF 요구, 대역별 수신 안테나 수, P-MPR
- 3GPP TS 38.214 6.2.1: SRS, 안테나 스위칭
- 3GPP TS 38.306: supportedSRS-TxPortSwitch 등 단말 능력
- 3GPP TS 38.321 6.1.3.8: PHR, MPE 필드
- 3GPP TS 38.331: UECapabilityInformation · UEAssistanceInformation
- Rel-16 NR UE 전력 절약: TR 21.916 19.1.3, 최대 MIMO 레이어 선호
- 3GPP TR 38.901 7.4.3: 차량 침투 손실
- Rel-19 TR 38.901 개정: 휴대폰 안테나 · 손 · 머리 가림. S. Svendsen et al., arXiv:2509.10357
