대리 모델: 비싼 모델의 입출력만 흉내 낸다

f(θ) : 레이 트레이싱 — 정확하지만 비싸다 → g(θ) ≈ f(θ) : 대리 모델 — 싸고 빠른 근사
θ = 설정 (틸트 · 방위각 · 전력 · Tx 위치 · 건물 지도 …) 학습 데이터 = RT 실행 결과 N개

흐름

설계점 고르기
(설정 N개)

→

RT 실행 N회
(비싼 부분)

→

대리 모델 학습
g ≈ f

→

질의 수천 회
(ms 이하)

→

상위 몇 개만
RT로 확인

① 파라미터 → KPI (저차원)

틸트 · 방위각 · 전력 몇 개 → 커버리지 · SINR 같은 숫자 하나
다항식 응답 표면 · 가우시안 과정(GP, 크리깅) — 4쪽, 예시 9~11쪽

② 지도 → 지도 (이미지)

건물 지도 + Tx 위치 → 화소마다 경로손실 (전파 지도)
U-Net 같은 CNN — RadioUNet · PMNet — 5~8쪽

핵심 대리 모델은 RT를 없애지 않는다 — RT로 만든 결과를 빠르게 재사용하는 도구. 정답지는 여전히 RT와 실측

대리 모델(surrogate model) = 메타모델 · 에뮬레이터라고도 부른다 · 흐름은 일반적인 구성

(약 45초) 대리 모델은 영어로 surrogate model이라고 하고, 메타모델이나 에뮬레이터라고도 부릅니다. 비싼 모델 f의 내부는 보지 않고 입력과 출력만 흉내 내는 싼 함수 g입니다. 흐름은 이렇습니다. 설정 N개를 골라 레이 트레이싱을 N번 돌리고, 그 결과로 대리 모델을 학습합니다. 그다음 질의는 수천 번이라도 밀리초 이하로 끝납니다. 마지막에 좋아 보이는 후보 몇 개만 다시 레이 트레이싱으로 확인합니다. 종류는 크게 둘입니다. 하나는 틸트나 방위각 같은 파라미터 몇 개에서 KPI 숫자 하나로 가는 저차원 대리 모델이고, 다른 하나는 건물 지도에서 전파 지도로 가는 이미지 모델입니다. 둘 다 레이 트레이싱을 없애는 것이 아니라 그 결과를 재사용하는 도구입니다.
