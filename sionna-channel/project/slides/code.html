# from sionna.rt import PathSolver, subcarrier_frequencies
# from sionna.phy.channel import time_lag_discrete_time_channel
paths = PathSolver()(scene, max_depth=5)
# ① CIR: 경로별 복소 이득 a, 지연 tau
a, tau = paths.cir(normalize_delays=False, out_type="numpy")
# ② CFR: 기저대역 부반송파 주파수에서 H[k]
freqs = subcarrier_frequencies(1024, 30e3)
h_f = paths.cfr(frequencies=freqs, normalize=False,
                normalize_delays=False, out_type="numpy")
# ③ FIR 탭: W = 1024 × 30 kHz = 30.72 MHz
l_min, l_max = time_lag_discrete_time_channel(30.72e6)
h_t = paths.taps(bandwidth=30.72e6, l_min=l_min, l_max=l_max,
                 normalize=False, out_type="numpy")

normalize_delays=False

절대 지연 유지. 기본값(True)은 첫 경로를 0으로 당긴다

normalize=False

경로손실 유지. True면 에너지가 정규화돼 PL 분석에 못 쓴다

W = K·Δf

(약 50초) 코드는 간단합니다. PathSolver로 경로를 구한 뒤, paths.cir로 CIR을, paths.cfr에 기저대역 부반송파 주파수를 넣어 CFR을, paths.taps에 대역폭과 탭 범위를 넣어 FIR 탭을 얻습니다. 여기서 세 가지 인자를 꼭 의식해야 합니다. 첫째, normalize_delays의 기본값은 True라서 첫 경로의 지연이 0으로 당겨집니다. 절대 지연이 필요하면 False로 둡니다. 둘째, normalize를 True로 두면 에너지가 정규화되어 경로손실 정보가 사라집니다. 셋째, FIR의 대역폭을 부반송파 수 곱하기 간격과 맞춰야 CFR과 FIR이 같은 대역을 봅니다. 예시는 Sionna RT 1.x 기준이고, TF 기반의 0.x에서는 cir_to_ofdm_channel과 cir_to_time_channel 함수를 씁니다. 함수 이름과 기본값은 버전에 따라 다르니 꼭 문서를 확인하세요.
