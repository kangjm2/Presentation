(약 50초) 먼저 검증입니다. 코드가 식을 맞게 푸는지 보는 코드 검증과, 이 장면과 이 설정에서 수치 오차가 충분히 작은지 보는 해 검증으로 나눕니다. NASA 표준의 구분입니다. 코드 검증은 답을 아는 문제로 합니다. 장애물 없는 장면은 Friis 식, 평면 지면은 2-ray 해석해, 단일 칼날 회절은 ITU-R P.526과 비교합니다. 송수신을 맞바꿔도 경로 이득이 같은지 보는 상반성 시험, 버전마다 기준 장면을 다시 돌리는 회귀 시험도 있습니다. 해 검증은 광선 수와 반사 차수를 늘려도 값이 안정한지, 시드만 바꿨을 때 칸 값이 얼마나 흔들리는지 봅니다. 이 시뮬 잡음은 Breakdown 화면에서 아직 측정하지 않은 칸입니다. 망 설정과 좌표 같은 입력 대조도 여기에 넣었습니다. 오른쪽 통과 기준은 예시입니다. 검증을 건너뛰면 버그와 입력 실수가 확인 단계에서 모델 오차로 보이게 됩니다.
