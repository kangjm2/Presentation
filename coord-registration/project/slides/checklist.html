정리 · 점검표

파이프라인 점검표

단계

확인할 것

받을 때

모든 위치 자료에 EPSG 코드 · 높이 기준(타원체 / 해발 / AGL) · 시간대를 함께 받는다

변환할 때

좌표계 하나로 통일 (예: 5179) · always_xy · 장면 원점 x₀, y₀와 회전을 기록

RU 입력

위치 · 높이(AGL + 지면) · 방위각(진북 ↔ 도북) · 틸트를 지도 위에서 한 번 더 확인

짝지을 때

시각 UTC 통일 · 지연 탐색 · 칸 크기 · 스냅 규칙 (칸당 표본 수 기준)

보고할 때

이동 탐색 결과(최소 자리 · 깊이)를 Breakdown과 함께 남긴다

from pyproj import Transformer
to_m = Transformer.from_crs("EPSG:4326", "EPSG:5179",
    always_xy=True) # 경도 먼저
x, y = to_m.transform(df.lon, df.lat)
x, y = x - X0, y - Y0 # 장면 원점
ix, iy = x // 20, y // 20 # 20 m 칸
df.t = df.t_utc + lag # 찾은 지연

작은 시험 하나

이미 아는 점(RU 위치 · 교차로)을 파이프라인에 넣어 지도 · 장면에서 같은 자리에 찍히는지 본다 — 왕복 1번이면 ④ ⑤ 같은 큰 실수는 다 걸린다

코드는 예시 (df · X0 · Y0 · lag는 프로젝트 변수) · ④ ⑤는 6쪽 번호 · EPSG:5179는 예시이며 프로젝트 공통 좌표계를 쓴다

(약 50초) 지금까지를 점검표로 묶었습니다. 받을 때는 위치 자료마다 EPSG 코드, 높이 기준, 시간대를 함께 받습니다. 변환할 때는 좌표계를 하나로 통일하고, 장면 원점과 회전을 기록합니다. RU는 위치, 높이, 방위각, 틸트를 지도 위에서 한 번 더 확인합니다. 짝지을 때는 시각을 UTC로 통일하고 지연을 찾고, 칸 크기와 스냅 규칙을 정합니다. 보고할 때는 이동 탐색 결과를 Breakdown과 함께 남기면 좋습니다. 오른쪽은 파이썬 pyproj로 쓴 예시입니다. always_xy를 켜서 경도를 먼저 넣고, 원점을 빼고, 20 m로 나눠 칸 번호를 만듭니다. 마지막으로 작은 시험 하나를 권합니다. 위치를 이미 아는 점, 예를 들어 RU나 교차로를 파이프라인에 넣어 지도와 장면에서 같은 자리에 찍히는지 보는 것입니다. 이것만 해도 큰 실수는 다 걸립니다.
