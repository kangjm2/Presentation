# CF는 안테나로 무엇을 하나

CF가 안테나로 하는 일 전부를 데이터가 흐르는 순서로 정리한 자료입니다. 가운데 있는 것은 한 줄입니다. **빔 하나 = 배열 인자(웨이트 × 포트 위치) × 포트 패턴(소자 × 서브어레이)**. 그 앞에 패턴 레코드와 좌표 · 부호가, 그 뒤에 솔버 · KPI · 실측 비교 · Adjust · 리비전이 있습니다. 내용은 2026-11-17 기준 코드(커밋 `ba85cf35`)와 ADR · 작업 기록(worklog) · 핸드오프 문서에서 확인한 사실을 정리한 브리프를 옮긴 것입니다.

다루는 내용은 다음과 같습니다.

- 왜 안테나인가: keller 드라이브 테스트에서 방위별 잔차 37 dB, 8분면 안에서는 2–5 dB
- 패턴 레코드: 2d-cuts(MSI) · 3d-grid(BASTA · 빔 · 포트), MSI 3D 덧셈 재구성, 업계가 단면 둘을 쓰는 이유와 그 한계(분리 가정), CF 변환에서 단면은 그대로 · 3D는 근사, 이득 단위(dBd 기본), physics_sha256
- 좌표와 부호: 방위(나침반, 북 0° 시계) vs Sionna yaw(수학 각, 동 0° 반시계) → yaw = 90° − 방위, 틸트(+ 아래, 변환 없음), θ · φ, 부호 함정 넷(전기 틸트 · MSI 시계 단면 · MSI 수직 방향 · 편파 기울기)
- 패턴의 출처: 해석 패턴 넷, 파일 형식 셋, 라이브러리 `lib:<id>`(없으면 오류)
- 빔 모델(중심): 웨이트 파일과 포트 번호, 식 P = E · S · Σ_pol |Σ w e^(+j2π r·p)|², 두 수직 단면의 곱, 그레이팅 로브 위치 표, 값의 출처(읽음 · 맞춤 · 가정), 켤레 선택, 이득 수준(2026-11-11), 측정 포트 패턴
- 솔버: 패턴 함수(전계 진폭 · 위상 0) · PlanarArray · 안테나 묶음, SSB 빔 레이어와 셀 = 최대, 1×1 규칙과 64포트 채널(H @ w), 가드레일 다섯
- 결과: SS-RSRP = 경로 이득 + RE당 전력(패턴 이득 포함, 배열 이득 없음), 실측 비교(대역폭 · 수신 안테나 · SSB 인덱스 짝짓기)
- Adjust, 리비전과 키, 콘솔 사용 흐름, 가정 · 모델에 없는 것 · 열린 질문

참고할 점:
- **출처와 줄 번호:** 각 장 아래쪽의 파일 · 줄 번호는 커밋 `ba85cf35` 기준입니다. 인용하기 전에 다시 확인하세요. `rt/`는 `engine/src/dtwin/rt/`입니다.
- **포트별 채널 위상(25쪽):** d_v 2.848 λ, 6° 아래로 나가는 경로(θ = 96°)에서 행별 경로차 z · cosθ = ∓0.45 · ∓0.15 λ → 위상 ∓161° · ∓54°. 원거리 경계 2D²/λ는 패널 대각 D ≈ 0.94 m(4행 × 2.848 λ, 8열 × 0.5 λ), 3849.6 MHz로 약 23 m입니다.
- **AF × S 확인(14쪽):** 표본 패널(4행 × 8열, d_v 2.848 λ, 서브어레이 4소자 · 서브 틸트 6°)에 임의 웨이트 32개를 넣고, 소자 128개를 직접 더한 값과 |AF|² · |S|²를 비교했습니다(차이 1.6 × 10⁻¹⁵). 포트 0만 서브 틸트 9°로 바꾸면 최대에서 −20 dB 안쪽에서 최대 1.2 dB 차이가 납니다.
- **이 덱에서 직접 계산한 것(15 · 16쪽):**
  - 16쪽 표는 d_v = 2.848 λ, 빔 6°(θ₀ = 96°)로 식 cosθ = cosθ₀ + k/d_v에서 계산했습니다. 브리프의 표와 같습니다.
  - 15쪽 그림은 numpy로 그렸습니다. 행 4개 · 2.848 λ · 빔 6.1°, 서브어레이 4소자 · 0.712 λ · 6°, 소자 수직 65°(38.901 모양). 세로 범위는 0 ~ −40 dB입니다. 표본 k = +1 로브의 “38 dB 아래”는 계산값이 아니라 문서값(worklog 2026-10-26, reliability-report)입니다.
- **6쪽 그림 B:** 개념도입니다. 두 그림에 3 dB · 10 dB 등고선을 그려 A(둥근 등고선)와 B(네모난 등고선)의 모양 차이를 보였습니다. B = max(A_h, A_v) + 0.25 · min(A_h, A_v)로, A(덧셈)와 두 단면이 똑같고 대각선만 다른 3D의 예입니다. 실제 안테나 값이 아닙니다.
- **2쪽 그림:** 개념도입니다(위에서 본 등방성 원과 38.901 소자 모양의 꽃잎). 37 dB · 2–5 dB만 실측 결과입니다.
- **함정(브리프 12장):**
  - 19쪽의 표본 이득 20.8 dBi · 25.5–27.6 dBi는 2026-11-11 이전 정규화 값입니다. 포트 채널 기준은 가장자리 24.6 vs 가운데 28.6 dBi, 포락선 3 dB 폭 76°입니다.
  - k = +1 위치는 출처가 엇갈립니다. 식은 수평 위 14.3°, reliability-report는 “16° 위”(d_v ≈ 2.63이어야 나옴). 저장된 세트의 `beams[].grating`으로 다시 확인하세요. “−36 dB”는 웹 테스트 픽스처에만 있는 값으로 결과가 아닙니다.
  - 22쪽 표준 조항(TS 38.215, TS 38.331 §5.5.3.3)은 사양서와 대조하지 않은 기억입니다. 인용 전에 확인하세요.
