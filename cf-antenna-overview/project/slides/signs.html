① 전기 틸트는 더하지 않는다

배열을 돌리는 것은 섹터의 기계 downtilt_deg뿐
벤더는 전기 틸트마다 파일을 따로 준다 → 틸트가 수직 단면에 이미 들어 있다
가져올 때 단면에서 measured_downtilt_deg를 재고, 선언값과 1.5° 안이면 tilt_baked_into_pattern = true

② MSI 수평 단면은 시계 방향 (ADR 0082)

파일 각도는 위에서 시계, 레코드는 반시계로 저장
out[k] = cut[(360 − k) % 360]
고치기 전에는 비대칭 단면이 좌우 반전 (physics revision 7) · 위에서 봐 정면 오른쪽 30° = φ −30°

③ MSI 수직 단면의 방향은 파일에 없다

"down"은 기본값이지 발견이 아니다
거꾸로 읽으면 아래로 숙인 주엽이 하늘을 본다

④ 편파 기울기 (ADR 0076)

벤더 +45° = 앞에서 본 "/" = Sionna ζ −45°
벤더 +45/−45 → Sionna cross (ζ −45, +45)
벤더 −45/+45 → CF cross_swapped · V/H → VH

(약 50초) 부호 함정 네 가지입니다. 첫째, 전기 틸트는 더하지 않습니다. 배열을 돌리는 것은 섹터의 기계 틸트뿐입니다. 벤더는 전기 틸트 설정마다 파일을 따로 주고, 그 틸트는 이미 수직 단면에 들어 있습니다. 가져올 때 단면에서 틸트를 재서 선언값과 1.5도 안에 들면 패턴에 틸트가 들어 있다고 표시합니다. 둘째, MSI 수평 단면은 위에서 봐 시계 방향입니다. CF는 반시계로 뒤집어 저장하고, 이것을 고치기 전에는 비대칭 단면이 좌우로 뒤집혀 계산됐습니다. 물리 리비전 7입니다. 셋째, MSI 수직 단면의 방향은 파일에 적혀 있지 않습니다. 아래가 플러스라는 것은 기본값일 뿐이고, 거꾸로 읽으면 숙인 주엽이 하늘을 봅니다. 넷째, 편파입니다. 벤더의 플러스 45도는 앞에서 본 슬래시 모양이고, Sionna에서는 제타 마이너스 45도입니다. 그래서 벤더의 플러스 마이너스 45는 Sionna cross가 됩니다.
