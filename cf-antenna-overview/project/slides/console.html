(약 50초) 콘솔에서는 여섯 걸음입니다. 먼저 Antennas 페이지에서 웨이트 파일을 가져옵니다. 전기 틸트는 필수이고, 빔폭과 주파수, 빔마다 가져올지와 SSB인지를 고른 뒤 Preview에서 선언값과 계산값을 비교하고 저장합니다. 둘째, 검사 카드, 단면, 빔 지도, 포트별 웨이트 패널을 살펴봅니다. 셋째, 아는 값이 있으면 Array 탭에서 고칩니다. 미리보기의 Effect 패널이 빔별 변화와 이 세트를 쓰는 계획을 보여주고, Apply하면 다음 리비전이 됩니다. 넷째, 측정 포트 패턴이 있으면 가져옵니다. 다섯째, Planner에서 섹터 안테나로 빔 레코드나 포트 레코드를 고르고 SSB 빔을 지정합니다. Engine 탭이 배열 모양을 잠가 줍니다. 여섯째, 오차 오버레이로 실측과 비교하고 뷰어의 드라이브 테스트 단면과 Adjust 후보를 봅니다. CLI로도 가져올 수 있지만 원본 파일을 남기지 않아 Array 탭을 쓸 수 없습니다.
