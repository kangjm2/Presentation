⑤ 보충 · 켤레 선택

켤레 선택은 맞춤 안에 숨은 그레이팅 별칭이다

간격을 맞출 때

두 규약(웨이트 그대로 · 켤레) 모두 어떤 간격에는 맞는다
하나가 다른 하나의 2π 보수 → 표본에서 2.84 λ vs 6.7 λ
→ 작은 쪽이 패널이다

간격이 주어졌을 때

예전 규칙 "빔을 더 아래로 숙이는 쪽" → 2.848 λ의 그레이팅 별칭을 잡았다
빔 13.6° · 좌우 반전 · 2.3 dB 낮음
→ 지금: 선언 틸트에서 최대인 규약 (ADR 0076 결정 3)

Sionna로 확인

모델 vs Sionna 포트 채널: 웨이트 그대로 0.0 dB · 켤레면 40.6 dB 차이 (ADR 0079)

왜 별칭인가

행 스텝은 2π로만 알 수 있다 → 같은 스텝에 맞는 (간격, 방향) 짝이 여럿 · 그중 하나는 그레이팅 방향을 주엽으로 착각한 것

교훈 맞춤이 "맞았다"고 해서 물리가 맞은 것은 아니다 — 선언값(틸트)과 독립 확인(Sionna 포트 채널)으로 별칭을 걸러낸다

(약 45초) 보충 장으로 켤레 선택 이야기입니다. 웨이트를 그대로 쓸지 켤레로 쓸지는 맞춤 안에 숨은 그레이팅 별칭 문제입니다. 행 스텝은 2파이 단위로만 알 수 있어서, 두 규약 모두 어떤 간격에는 들어맞습니다. 표본에서는 2.84 파장과 6.7 파장이었고 작은 쪽이 실제 패널입니다. 간격이 주어진 경우에는 예전에 빔을 더 아래로 숙이는 쪽을 골랐는데, 이것이 2.848 파장의 그레이팅 별칭을 잡아서 빔이 13.6도로 가고 좌우가 뒤집히고 2.3 dB 낮게 나왔습니다. 지금은 선언한 틸트에서 최대가 되는 규약을 고릅니다. Sionna의 포트 채널로 확인하면 웨이트 그대로일 때 모델과 0.0 dB, 켤레면 40.6 dB 차이가 납니다. 맞춤이 맞았다고 물리가 맞은 것은 아니라는 교훈입니다.
