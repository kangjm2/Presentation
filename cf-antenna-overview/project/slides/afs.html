④ 보충 · AF × S를 한 번 곱해도 되나

AF × S를 한 번만 곱하는 이유 — 똑같은 것은 묶어낸다

F = Σ_n Σ_m E · w_n · s_m · e^(j2π r·(p_n + z_m))
= E · [ Σ_n w_n e^(j2π r·p_n) ] · [ Σ_m s_m e^(j2π z_m cosθ) ] ← AF: 포트 32개 · S: 포트 하나의 소자 4개

배열 원점

p_n → AF
원점 → 포트 중심

z_m → S
포트 중심 → 소자

점 = 소자(E) · 상자 = 포트(S)
상자 4개 = 한 열 (AF는 4행 × 8열)

조각

무엇 하나로 계산

무엇을 합치나

포트 하나

배열 전체

포트 32개 (편파 하나)

분배법칙

w₁·S·e₁ + … + w₃₂·S·e₃₂ = S · (w₁e₁ + … + w₃₂e₃₂)
S는 모든 포트가 같으니 32번 대신 한 번 — 포트를 합치는 일은 AF만 한다

기준점 둘

p_n은 배열 원점에서 포트 중심까지 · z_m은 포트 중심에서 소자까지 → 둘이 맞아야 위치 위상이 AF에 한 번만 들어간다

수치 확인 (표본 패널)

소자 128개를 하나하나 더한 값 vs |AF|² · |S|²
차이 1.6 × 10⁻¹⁵ = 같다

조건 셋

① 모든 포트 패턴이 같다 (서브어레이 · 소자 · 방향)
② 원거리 (모든 포트에서 같은 방향)
③ 포트 패턴은 포트 중심 기준

깨지면

포트 0만 서브 틸트 9° → 주엽 근처 최대 1.2 dB 차이 · 그때는 포트마다 Σ w_n P_n e^(…)로 따로 더한다

편파 둘은 마지막에 전력으로 더한다 · CF는 측정 포트도 편파별 평균 하나로 푼다 (20 · 31쪽) · 수치는 이 덱에서 numpy로 계산

(약 55초) 보충 장입니다. 포트마다 서브어레이가 있는데 왜 배열 인자에 S를 한 번만 곱하고 끝내는지 보겠습니다. 소자 128개를 하나하나 더하는 것에서 시작하면, 소자 위치는 배열 원점에서 포트 중심까지 p_n과 포트 중심에서 소자까지 z_m의 합입니다. 지수의 덧셈은 곱으로 나뉘니, 위 식처럼 n에만 달린 부분과 m에만 달린 부분으로 나눌 수 있습니다. 앞 괄호가 포트 32개를 더하는 배열 인자이고, 뒤 괄호가 포트 하나 안의 소자 넷을 더하는 S입니다. S에는 n이 없습니다. 모든 포트가 같은 서브어레이를 가지니 S를 32번 곱하는 대신 한 번 묶어낸 것으로, 분배법칙과 같습니다. 포트를 합치는 일은 배열 인자만 하고, S는 포트 하나의 값이 모든 포트에 똑같이 해당하는 것입니다. 표본 패널로 직접 더해 보면 차이는 10의 마이너스 15승으로 같습니다. 조건은 세 가지입니다. 모든 포트 패턴이 같고, 원거리이고, 포트 패턴이 포트 중심 기준이어야 합니다. 포트 하나만 서브 틸트가 달라도 주엽 근처에서 1.2 dB까지 틀어지고, 그때는 포트마다 따로 더해야 합니다.
