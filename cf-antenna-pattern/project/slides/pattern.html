Sionna가 각도를 넣으면 전계 진폭을 돌려준다

2D 단면(MSI):
G(θ,φ) [dB] = 최대이득[dBi] − H감쇠(φ) − V감쇠(앙각)
앙각 = 90° − θ (부호는 vertical_positive)
반환 = 10^(G/20) ← 전력이 아니라 전계 진폭

3D 격자 (BASTA · 빔 · 포트)

181 × 360 격자에서 쌍선형 보간 — θ는 범위 안으로 자르고, φ는 한 바퀴 이어 붙임 · 반환 = 10^((최대이득 + 상대값)/20)

등록 이름

lib-<id> — Sionna PolarizedAntennaPattern, 편파 모델 tr38901_2

MSI 재구성의 한계

두 단면 위에서는 정확, 대각선은 실제보다 더 감쇠 · 3GPP 패턴과 달리 30 dB 바닥이 없다

MSI 방식: 수평 + 수직 감쇠 (dB 합) — 바닥 없음

(약 55초) 이제 패턴이 Sionna에 들어가는 방식입니다. 레코드는 lib 접두어 이름의 Sionna 안테나 패턴으로 등록되고, Sionna가 경로의 각도를 넣으면 패턴 함수가 값을 돌려줍니다. 주의할 점은 돌려주는 값이 전력이 아니라 전계 진폭, 즉 전력의 제곱근이라는 것입니다. MSI처럼 2D 단면 두 개만 있으면, 최대 이득에서 수평 감쇠와 수직 감쇠를 dB로 빼서 3D를 만듭니다. 선형으로는 두 단면을 곱하는 셈입니다. 3D 격자는 쌍선형 보간합니다. 오른쪽 그림은 38.901 모양의 단면으로 만든 예시입니다. MSI 방식은 두 단면 위에서는 정확하지만, 대각선 방향에서는 감쇠가 그대로 더해져, 예를 들어 방위 100도 앙각 48도에서 34 dB가 됩니다. 3GPP 패턴은 같은 방향에서 30 dB 바닥에서 멈춥니다. 그래서 MSI 재구성은 근사이고, 주엽 바깥 대각선 방향에서 감쇠를 실제보다 크게 잡습니다. BASTA 같은 3D 격자에는 이런 근사가 없습니다.
