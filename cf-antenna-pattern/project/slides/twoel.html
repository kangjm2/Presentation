(약 55초) 12쪽의 “배열 이득 0”을 소자 둘로 손 계산해 보겠습니다. 간격 0.5 파장의 두 소자에 경로 하나가 방위 30도에서 들어오면, 거리 차 때문에 두 소자 채널의 위상이 90도 다릅니다. 그래서 소자별 채널은 a 곱하기 1과 j입니다. CF의 지점 전력은 안테나 쌍의 평균이라, 두 소자의 크기가 같으니 그대로 a 제곱, 0 dB입니다. 여기에 웨이트를 곱하면 달라집니다. 위상을 맞춘 정합 웨이트 1, 마이너스 j를 곱하면 오른쪽 그림처럼 두 화살표가 같은 방향으로 이어져 전력이 두 배, 플러스 3 dB가 됩니다. 정면 웨이트 1, 1이면 직각으로 이어져 0 dB, 반대 웨이트 1, j이면 서로 상쇄되어 널입니다. 웨이트의 크기 합은 1이라 총 송신 전력은 같습니다. 그러니 3 dB는 전력을 더 쓴 게 아니라 위상을 맞춰 더한 결합 이득이고, 소자 N개면 최대 10 로그 N, 64개면 18.1 dB입니다. 배열 이득은 웨이트를 곱해야만 생기고, 방향이 틀리면 오히려 손해라는 것이 핵심입니다.
